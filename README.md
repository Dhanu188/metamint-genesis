# 🖼️ MetaMint – Decentralized NFT Marketplace

MetaMint is a modern, decentralized NFT marketplace that allows users to connect their wallets, mint NFTs with custom metadata, and view them live — all built on the Polygon Amoy testnet.

## 🧠 Features

- 🔐 Connect Wallet (RainbowKit + Wagmi v2)
- 🎨 Mint NFTs with name, description, and image
- 🖼️ Live NFT Preview from metadata
- 🌈 Responsive UI with fade-in animations & gradient backgrounds
- 🌍 Polygon Amoy testnet integration

## ⚙️ Tech Stack

- **Frontend:** Next.js 14 (App Router), TypeScript, Tailwind CSS
- **Wallet Integration:** RainbowKit v2, Wagmi v2, Viem
- **Smart Contracts:** Solidity (ERC-721), deployed on Polygon Amoy via Alchemy + Hardhat
- **Deployment:** Vercel
